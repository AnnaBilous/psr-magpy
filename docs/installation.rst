Installation
===========

Prerequisites
------------

Before installing psr-magpy, ensure you have the following prerequisites:

* Python 3.8 or higher
* NumPy
* SciPy
* Matplotlib
* Astropy

Basic Installation
-----------------

You can install psr-magpy using pip:

.. code-block:: bash

   pip install psr-magpy

Development Installation
-----------------------

For development, you can install psr-magpy from source:

.. code-block:: bash

   git clone https://github.com/yourusername/psr-magpy.git
   cd psr-magpy
   pip install -e .

This will install the package in development mode, allowing you to modify the code and see the changes immediately.
